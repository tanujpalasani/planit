## Source Code Structure (`src/`)

### 📄 main.jsx
**Purpose:** React application entry point
**Functionality:**
- Imports React and ReactDOM
- Imports App component
- Imports global styles (globals.css)
- Creates React root and renders App component in strict mode
- Mounts to `#root` element in index.html

```jsx
import React from "react";
import ReactDOM from "react-dom/client";
import App from "./App.jsx";
import "./styles/globals.css";

ReactDOM.createRoot(document.getElementById("root")).render(
  <React.StrictMode>
    <App />
  </React.StrictMode>
);
```

### 📄 App.jsx
**Purpose:** Root application component
**Functionality:**
- Imports AppRouter from routes folder
- Returns AppRouter component
- Acts as the main wrapper for all routes

```jsx
import AppRouter from "./routes/AppRouter";

function App() {
  return <AppRouter />;
}

export default App;
```

### 📁 routes/
**Purpose:** Application routing configuration
**Status:** 1 file

#### 📄 AppRouter.jsx
**Purpose:** Central routing configuration for the entire application
**Props:** None
**Router Setup:** BrowserRouter wrapping all routes

**Public Routes:**
1. `/` → Home component
2. `/login` → Login component
3. `/signup` → Signup component

**Protected Routes:**
- Path: `/dashboard`
- Layout wrapper: MainLayout component
- Route: /dashboard → Dashboard component
- *Note: Route structure allows for nested routes under /dashboard (e.g., /dashboard/projects, /dashboard/tasks)*

**Routing Strategy:**
- Public pages (/, /login, /signup) render directly without layout wrapper
- Protected pages render through MainLayout (sidebar + navbar wrapper)
- Uses React Router v7 with nested routes pattern

**Route Structure:**
```
<BrowserRouter>
  <Routes>
    <Route path="/" element={<Home />} />
    <Route path="/login" element={<Login />} />
    <Route path="/signup" element={<Signup />} />
    
    <Route element={<MainLayout />}>
      <Route path="/dashboard" element={<Dashboard />} />
    </Route>
  </Routes>
</BrowserRouter>
```
